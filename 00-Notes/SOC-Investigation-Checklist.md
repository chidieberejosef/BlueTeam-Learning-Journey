# SOC Investigation Checklist

## Identity
- Who is the user?
- Which department are they in?
- Is the activity expected for their role?

## Host
- Hostname
- Source IP
- Operating System
- Previous alerts

## Process
- Process name
- Parent process
- Command line
- Hash
- Digital signature

## Network
- Destination IP
- Destination domain
- Port
- Protocol
- Reputation

## Timeline
- What happened before?
- What happened after?

## Threat Intelligence
- VirusTotal
- AbuseIPDB
- WHOIS
- MISP (future)
- OpenCTI (future)

## MITRE ATT&CK
- Initial Access
- Execution
- Persistence
- Privilege Escalation
- Defense Evasion
- Credential Access
- Discovery
- Lateral Movement
- Collection
- Exfiltration
