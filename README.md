# Blue Team Learning Journey

Welcome to my Blue Team Learning Journey.

This repository documents my progression from beginner/intermediate cybersecurity knowledge to becoming an employable Security Operations Center (SOC) Analyst.


## Objectives

- Build a professional SOC home lab
- Learn enterprise defensive security
- Practice real-world incident response
- Develop detection engineering skills
- Master SIEM technologies
- Learn threat hunting
- Build DFIR skills
- Create a portfolio for recruiters and hiring managers
